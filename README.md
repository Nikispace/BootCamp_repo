# Simple Python Calculator

This is a basic command-line calculator built in Python.  
It can perform addition, subtraction, multiplication, and division on two numbers.

## Features

- Add two numbers
- Subtract two numbers
- Multiply two numbers
- Divide two numbers (with simple zero-division handling)

## How to Run

1. Make sure you have Python installed (Python 3.x).
2. Open a terminal or command prompt.
3. Navigate to the project folder:
   ```bash
   cd cipherschool-calculator
   ```
4. Run the script:
   ```bash
   python calculator.py
   ```
5. Follow the on-screen instructions to choose an operation and enter numbers.

## Project Structure

- `calculator.py` – Main Python script containing the calculator logic.
